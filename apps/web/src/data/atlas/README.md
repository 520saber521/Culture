# 江苏文化图鉴数据

## 导航与阅读记忆

- 城市可在展场顶部直接切换。切换使用短淡入和位移，返回地图仍使用轮廓转场。
- `?atlas=1&city=nanjing&item=nanjing-cloud-brocade&theme=textile` 可直达条目；城市和条目可省略。无效 ID 自动移除；跨城推荐保留原展场作为返回位置。
- 主题切换替换当前历史记录，进入城市/条目建立新记录；浏览器前进后退会取消未完成的转场并恢复目标状态。
- 当前标签页的 `sessionStorage` 保存每座城市、主题、分类下的阅读位置，以及条目位置和最近浏览城市。存储不可用时保留内存中的浏览体验，不阻断页面。
- 城市与条目都有复制链接入口；剪贴板不可用时展示可选中的链接。分享链接只包含图鉴参数，不附带其他查询参数。
- 七项延伸可按文化类别筛选，分类计数来自当前七项内容。主题栏显示实际匹配城市数与条目数。

运行 `node --test apps/web/src/data/atlas/*.test.mjs` 检查内容、主题、主角排序、URL 参数和阅读记录容错。

## 图片预留与城市视觉

`visuals.js` 集中管理十三市的装饰图形、色调、主角条目，以及 `atlasMedia` 图片配置。2026-11-16 已接入用户提供并确认城市对应关系的十三张城市封面；文化条目仍使用独立素材或装饰纹样，不将城市封面当作文物、工艺实物的照片。

封面网页资源在 `public/images/atlas/*-hero.webp`，保留原始尺寸，WebP quality 88。原始 PNG 与附件顺序清单保存在 `src/assets/atlas-originals/`，不打入网页包。13 张原图合计约 33.61 MiB，网页资源合计约 3.78 MiB。每张图配置了桌面 `position` 与手机 `mobilePosition`；城市封面优先加载，其余配图延迟加载。来源记录为用户提供，未推断作者、拍摄地点、图片生成方式或对外授权。

在 `apps/web/public/images/atlas/` 放入获准使用的图片，然后配置：

```js
atlasMedia.nanjing = {
  src: '/images/atlas/nanjing-hero.webp',
  position: '65% 50%', // 调整裁切焦点
  alt: '图片的实际内容描述',
  credit: '作者姓名 · 授权说明',
  sourceUrl: '原始来源地址',
  license: '明确的授权方式',
}
// 条目卡片与详情共用同一素材；城市封面独立配置。
atlasMedia['nanjing-cloud-brocade'] = { /* 相同字段 */ }
```

城市封面建议横图 1920×900 以上，重点主体放右侧以留出左侧标题；主角图建议 1400×1000，普通卡片建议 1000×750。图片空间已固定，加载或失败不会让布局塌陷；失败回退至各城装饰纹样。

默认主角由 `cityVisuals.feature` 指定，主题筛选时匹配条目优先成为主角。其余七项保留在后续网格中。主题代表条目来自实际内容数据，不另造文化关联。

`content.js` 提供十三市、104 个条目、文化主题、关联推荐。分类是编辑分组，不表示官方非遗认定；没有设置未经核验的非遗总量或景点数量。

## 来源与素材

- `jiangsu.geo.json`：2026-11-13 下载自 https://geo.datav.aliyun.com/areas_v3/bound/320000_full.json ，本地保存十三市 MultiPolygon 边界；浅浮雕高度仅为视觉设计，不表示海拔。
- 正文是编辑导读，`sources` 区分具体资料页与 `kind: directory` 资料入口。目录链接不代表每条事实已逐条完成审核；正式内容发布前仍需编辑逐条补全权威出处，尤其人物、古建沿革及民俗历史。
- 内容记录的 `image` 可为空，城市封面通过 `atlasMedia` 加载。尚无独立配图的文化条目保留原创装饰示意，不借用城市封面冒充对应实物。
- 换入图片时同时填写 `imageCredit`（作者、来源 URL、授权方式）；优先本地文件。加载失败自动回退纹样。

## 交互验证

运行 `node --test apps/web/src/data/atlas/content.test.mjs` 检查行政区覆盖、条目唯一性、四类各两条、观察点、来源字段与主题引用。

浏览器已验证 1440×900、1366×768、1920×1080、390×844，十三市进入、104 卡片、主题恢复、嵌套滚动、详情及 Esc 返回、减少动态效果、WebGL 失败回退。构建通过；Vite 仍提示主包和 Three.js chunk 较大，地图与 Three.js 已延迟加载。

界面状态：overview → lifting → focusing → entering → city → item → closing-item → city → leaving → retreating → overview。先抬升区域，再推进镜头，最后将投影后的行政轮廓展开为城市展场；返回逆序执行。转场期间不接收新的城市选择。地图在可见时以限帧水面动画绘制，城市展场遮盖、页面隐藏或减少动态效果时按需绘制；路由退出释放几何体、共享纹理、材质、监听器与定时器。
