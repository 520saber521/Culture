# 前端页面设计约定

修改或新增页面视觉、导航、按钮、表单时，先阅读 [江苏文创视觉规范](../../docs/design/江苏文创视觉规范.md)。它记录了用户确认的设计方向与现有实现；用户在当前任务中的新要求优先。

- 对外平台品牌使用“江苏文创”，不是“江南文创”。
- 复用 `src/styles/brand.css`、`src/components/SiteNavigation.vue` 和 `src/components/BrandButton.vue`。
- 主按钮沿用毛笔字、细内框、胭脂红实体底、分隔箭头的题签样式；禁止高光渐变、玻璃效果与厚重投影。
- 首页轮播首屏导航保持透明，其他区域使用实体底色。
- 新增毛笔文案时检查本地字体子集是否覆盖相应字符。
- 限定改造范围，保留接口、路由和业务交互；不要因统一视觉顺带重写地图、城市页面、AI 创作或认证逻辑。
- 更新共享设计语言时同步视觉规范；文档修改无需额外执行业务测试。
