# 江苏文创视觉规范

状态：已用于全站导航、登录 / 注册页、文化地图、走进江苏和参与创作页，作为其他页面后续改造的基准。更新日期：2026-11-16。

## 设计定位

**江苏文创 · 现代东方题签风格。** 以毛笔标题、胭脂红题签按钮、茶绿画页、鹅黄衬签和细栏线建立识别度。传统书画的表现力用于品牌与内容，现代排版用于操作和阅读。

平台地域是“江苏”，品牌名称使用“江苏文创”；不要将平台名称改为“江南文创”。江南可作为具体作品、插画或地域文化的题材名称。

参考新中式复古商业美术的字体、颜色与布局思路，不直接复制其他品牌的标识、商业插画或宣传文字。避免将风格简化为“米白底加红色按钮”。

## 字体与层级

- `--brand-display`：毛笔展示字体。用于品牌名、简短主标题、题签主按钮。保持正常字重，不叠加描边、发光或阴影。
- `--brand-serif`：宋体类。用于栏目标题、题签注释、少量文化旁注。
- `--brand-sans`：现代黑体类。用于导航、输入框、正文、表格和长说明。

建议尺度：桌面品牌主标题 48–66px，页面标题 34–42px，正文与表单 14–16px，辅助文字 12–13px。细小装饰文字不承载必要操作信息。移动端主标题缩小到 33–39px，保留有意义的断句，避免单个字意外落到下一行。

**字体子集限制：** 当前本地 `public/fonts/jiangnan-display.woff2` 是 Ma Shan Zheng 的字符子集，并非完整字库。文件名与 CSS 字体族保留历史命名，不是对外品牌名称。字符范围记录在 `public/fonts/display-characters.txt`。增加标题或按钮文案时，必须检查新字符是否齐全；缺字时更新子集或统一使用合适的回退字体，避免同一标题混入两种字形。保留 [SIL OFL 授权文件](../../apps/web/public/fonts/MaShanZheng-OFL.txt)，不要复制系统商业字体到仓库发布。

## 核心组件：题签主按钮

设计语言：**毛笔字、细内框、胭脂红实体底、分隔箭头**。

- 外形使用横向题签比例，4px 小圆角。外框为深红，内框向内缩进 3px，以 1px 暖色细线构成印刷层次。
- 主文字采用毛笔字体，当前基础字号 23px、字距 3px。常用操作名宜为 2–4 个汉字，保持动作含义明确，例如“登录”“注册”。
- 右侧箭头与文字之间保留一条短竖线；不添加通用人像图标，不堆叠多个装饰图标。
- 导航按钮高 40px，手机端 36px；表单主按钮高 50px、宽度跟随表单。其他页面优先使用 44–50px 高度，宽度按文字和布局确定。
- 悬停只加深背景；键盘聚焦显示清晰外轮廓；禁用用灰化色；加载时禁用点击，右侧箭头替换为转圈指示，并提供“保存中…”等可读文字。
- 禁止渐变、高光扫过、毛玻璃、厚阴影、悬停放大或跳动。
- 页面主操作使用题签按钮。取消、返回、筛选、分页和删除等操作使用克制的文本或细边框按钮，避免所有按钮争夺注意力。

### Vue 用法

`BrandButton` 支持 `type`（默认 `button`）、`loading`、`disabled`，默认插槽承载按钮文案；原生点击事件和 class 通过 Vue 属性透传。组件本身不调用接口或决定路由。

```vue
<script setup>
import BrandButton from '@/components/BrandButton.vue'

defineProps({ submitting: Boolean, canSubmit: Boolean })
const emit = defineEmits(['submit'])
</script>

<template>
  <form @submit.prevent="emit('submit')">
    <!-- 页面表单字段 -->
    <BrandButton
      type="submit"
      class="page-primary-action"
      :loading="submitting"
      :disabled="!canSubmit"
    >
      {{ submitting ? '保存中…' : '保存' }}
    </BrandButton>
  </form>
</template>

<style scoped>
.page-primary-action { height: 50px; min-width: 128px; }
</style>
```

示例的业务处理由父组件接入，并需补齐“保存中…”的字体字符。不要同时在表单 submit 与按钮 click 中重复发起同一个请求。页面一般只设置按钮尺寸，不覆盖内部字形、框线和箭头样式；需要公共变体时在组件和全局样式中集中实现。

## 导航

全站使用 `SiteNavigation`，不复制独立导航。桌面高度 74px，760px 及以下为 64px；左右间距使用 `--brand-gutter`。页面顶部布局使用 `--brand-nav-height` 预留空间，避免固定导航遮挡内容。

**首页轮播首屏透明，是已确认的设计例外。** 透明态使用浅色文字，轮播之外恢复白色实体底与墨色文字。无需毛玻璃。菜单顺序、字体、间距、题签登录按钮及用户菜单保持同一体系。选中状态采用短细线；实体态用胭脂红，透明态以可读性为先。

## 页面排版与图片

- 品牌叙事与高频操作分区：茶绿承载品牌画页，白色承载表单和工具内容；用边界、栏线和字号建立秩序。
- 题签、竖排旁注、印章和栏线选择性使用。每个区块只保留必要装饰，不能像古风游戏或仿古证书。
- 插画需有完整构图，可用淡彩、水彩或复古印刷质感；避免零散传统图标拼贴。
- 用户提供的完整画作优先按原始比例显示。当前登录图片为 [茶点雅集水彩](../../apps/web/public/jiangsu-login-tea-watercolor.png)，使用 `height: auto` 与 `object-fit: contain`，不要拉伸或裁去主体。
- 登录页的插画是页面特定资源，不能自动变成每个业务页面的背景。城市页、图库、创作页应展示各自真实内容。
- 纸张肌理只用于局部品牌区域，保持低对比，不覆盖表单和正文。
- 手机端优先保留品牌标题与操作；可以隐藏辅助插画和旁注，不能隐藏必要字段或功能入口。

## 表单与反馈

输入框使用浅色实体背景、1px 边框、4px 圆角，当前参考高度 48px；聚焦以品牌红细边反馈。标签、错误信息、键盘操作、密码显示切换及自动填充应正常工作。登录 / 注册切换采用文本与细线，不用大胶囊。

保留原有接口、路由、状态处理与权限规则。未接入功能明确提示状态，不能以假成功替代真实业务流程。

## 改造验收

1. 品牌名称是江苏；使用共享变量和公共组件，没有新增独立红色按钮样式。
2. 必要文案清晰、字体字符完整；主操作可辨识，装饰不抢内容。
3. 桌面、平板、390px 和 320px 宽度无横向溢出，标题不意外断成孤字，导航不覆盖内容。
4. 登录、注册、普通提交按钮具有正常、悬停、聚焦、禁用、加载状态；不重复提交。
5. 首页轮播透明导航及切换到实体导航的逻辑仍有效；已登录与未登录入口均可用。
6. 按修改范围验证现有路由与业务；涉及组件或样式代码时运行前端构建，记录未验证的后端行为。


## 地图水体（2026-11-17）

长江与太湖使用真实 OpenStreetMap 水域、中心线及入海口海岸线，统一转换为底图坐标后嵌入 Three.js 地形。旧的 `AtlasWaters.vue` 装饰背景已停用，不再用手绘曲线表示实际水系。完整来源、提取边界与精度说明见 [water-sources.md](../../apps/web/src/data/atlas/water-sources.md)。

`data/atlas/water.js` 集中管理青灰水色、柔和反射、流速和帧率。长江由真实主流与支汊的局部流向、沿程距离驱动细纹，太湖采用独立的交叠风纹。水面不透明，不发光，不移动岸线，不使用整层 CSS 背景平移。水体低于陆地顶面，湖岛保留为陆地。

水体与地图共用一个渲染循环和相机；离开地图、页面不可见时暂停，城市展场完全覆盖后停止持续绘制。减少动态效果和 WebGL 降级时保留静态真实水面。色彩和变化幅度始终低于城市标签的视觉权重。数据署名必须保持可见。

## 文化图鉴章节页（2026-11-17）

范围为 `/culture`、`/feiyi`、`/celebrities`、`/traditional-arts`、`/gallery`。用户补充的参考强调有笔触与拙趣的标题、暖纸底与复古手绘美术，因此这些章节页使用毛笔短标题、浅赭题签和少量印章；筛选、正文及详情仍保持清晰的黑体阅读层级。

- `CultureChapterHeader.vue` 提供章节主视觉和五类目录，选中项随页面变化。
- `CulturePageState.vue` 提供加载、空结果与重试反馈，失败时保留筛选条件。
- `culture-chapters.css` 统一四个子页面的筛选区、图卡、详情与响应式布局。
- 本地 `jiangnan-chapters.woff2` 沿用 Ma Shan Zheng 的 SIL OFL 授权，字符清单为 `public/fonts/chapter-characters.txt`；新增展示文案需同步检查覆盖。
- 章节插画复用现有 `jiangnan-atelier-hero.png`，仅作为主视觉装饰，不冒充真实内容记录或展品图片。卡片仍使用原接口图片。
- 上传入口复用 `BrandButton`；分类、重置及重试使用克制的文字或细框操作。
