# 江苏十三市首批图片素材清单（26张）

已有13张城市封面继续用于城市主视觉。本批为13个默认主角条目各补2张：A用于展场代表文化全貌，B用于详情细节。博物馆入口改为文字题签，无需补图。

## 文件规格

- A建议横向3:2、至少1800×1200；B建议横向4:3、至少1600×1200。保留原片，不必为凑比例裁掉主体，低于建议尺寸也可先提供原文件。
- 主体周围留约10%余量；不加水印、文字、边框或拼图。完整器形、题字、文献不可裁切的部分请备注。
- 接受JPG、PNG、WebP；下表WebP是网站目标文件名，无需自行转换。
- 每对照片尽量来自同一作品、同一地点或同场演出，不用同一张图裁切两次。记录实际名称和地点，无法确认的信息留空。
- 附拍摄者/权利人、来源、使用许可和署名要求；“来自官网”不能代替许可。演出、展陈照片请说明拍摄及使用条件。
- 主题对应当前文化条目，不表示某馆当前展览；不要用其他城市、相似建筑或其他曲种替代。
