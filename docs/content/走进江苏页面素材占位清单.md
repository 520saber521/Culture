## 占位与接入

- 组件：apps/web/src/components/CultureMedia.vue。
- 配置：apps/web/src/data/cultureMediaAssets.json，初始为空，不发起不存在的图片请求。
- 页首键：culture:hero。
- 条目键：culture:{编码后的city}:{featureType}:{编码后的id}:cover 或 :detail；由 cultureMediaKey 生成。浏览器 DOM 的 data-media-slot 可直接查看准确键，避免手工猜测ID。
- 配置支持 src、alt、credit、sourceUrl、license。卡片未配置时沿用接口 imageUrl；设 src:null 可显式停用不适合的旧图片。详情只使用独立配置，不自动回退卡片图。
- 建议文件存放于 apps/web/public/images/culture/；登记 src 后生效，复制文件不会自动上线。
- JPG、PNG、WebP原文件均可提供；实际接入时再压缩。附作品/地点名称、拍摄者或权利人、来源、使用许可、署名与不可裁切范围。

示例（图片提供后登记）：

```json
{
  "culture:hero": {
    "src": "/images/culture/culture-hero.webp",
    "alt": "填写实际画面内容",
    "credit": "填写署名",
    "sourceUrl": "填写真实来源",
    "license": "填写使用许可"
  }
}
```
