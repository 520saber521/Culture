# 项目文档

文档按用途分组：

- [`design/江苏文创视觉规范.md`](design/江苏文创视觉规范.md)：全站风格基准、题签按钮、配色字体与页面改造用法。

- [`product/PRD.md`](product/PRD.md)：产品目标、用户场景、现状能力、下一阶段需求与验收口径。
- [`planning/项目规划.md`](planning/项目规划.md)：阶段安排、交付条件、近期清单和主要依赖。
- [`technical`](technical/)：技术实现文档、页面讲解文档。
- [`technical/复用模块接入.md`](technical/复用模块接入.md)：本轮接入的地图、动效、图片存储和内容编辑模块。
- [`presentation`](presentation/)：项目展示大纲、作品介绍的 Markdown 和 Word 版本。
- [`copyright`](copyright/)：软件著作权提交与打印材料。

日常开发优先更新 Markdown 文件；Word、PDF 和打印版文件作为交付材料保留。

涉及产品范围变更时，先更新 PRD 的需求编号与验收口径，再同步项目规划和技术文档。`presentation` 和部分 `technical` 文档保留历史表述，判断当前实现请以代码、根目录 README 及上述两份现状文档为准。
