# 江苏文化传承与创新平台页面讲解文档

## 1. 首页

### 1.1 功能概述
首页是平台的入口页面，集中展示江苏文化的核心内容和特色功能。主要功能包括文化概览、江苏文化地图、文化动态等，为用户提供直观的文化体验和快速导航。

### 1.2 核心组件
- **轮播图**：展示江苏文化特色的视频和图片背景，包含标题和描述。
- **文化概览**：展示江苏文化数据统计（非遗项目、文化景点、特色美食、历史名人）和文化精粹推荐。
- **江苏文化地图**：基于高德地图的交互式地图，展示十三市文化特色。
- **文化动态**：展示最新文化资讯，包括深度推荐和新闻列表。

### 1.3 交互流程
1. **轮播图交互**：自动轮播，支持手动切换，鼠标悬停暂停。
2. **文化地图交互**：点击城市标记显示详细文化信息，包含文化特色、热门景点、特色美食等。
3. **导航交互**：点击导航菜单跳转到对应页面。
4. **新闻交互**：点击新闻标题查看详细内容，点击“查看更多资讯”加载更多新闻。

### 1.4 设计规范
- **色彩方案**：以传统文化色彩为基础，主色调为红色、金色等，体现江苏文化的深厚底蕴。
- **字体规范**：标题使用加粗字体，正文使用清晰易读的字体，确保良好的阅读体验。
- **布局规范**：采用响应式布局，适配不同设备屏幕，确保在PC端和移动端均有良好的显示效果。
- **视觉元素**：使用传统文化元素作为装饰，如中国结、祥云等，增强文化氛围。

### 1.5 技术实现要点
- **轮播图实现**：使用Element Plus的Carousel组件，支持视频和图片背景。
- **地图实现**：集成高德地图API，实现城市标记和信息窗口。
- **数据加载**：通过API调用获取文化动态数据，支持分页加载。
- **动画效果**：使用Vue的过渡动画，增强用户体验。

### 1.6 常见问题解答
- **地图加载失败**：检查网络连接，确保高德地图API密钥正确配置。
- **轮播图不自动播放**：检查浏览器是否阻止了自动播放，或检查轮播图配置。
- **新闻加载缓慢**：可能是网络问题或服务器响应缓慢，建议刷新页面重试。

## 2. 文化库页面

### 2.1 功能概述
文化库页面集中展示江苏省的文化资源，包括非遗项目、历史名人、传统艺术等，支持分类浏览和详情查看，为用户提供全面的文化资源查询服务。

### 2.2 核心组件
- **分类导航**：按文化类型（非遗、名人、艺术等）进行分类导航。
- **资源列表**：展示文化资源的列表，支持分页和筛选。
- **资源详情**：点击资源项查看详细信息，包括图片、视频、介绍等。
- **搜索功能**：支持按关键词搜索文化资源。

### 2.3 交互流程
1. **分类浏览**：点击分类导航切换不同类型的文化资源。
2. **资源查看**：点击资源列表项查看详细信息。
3. **搜索交互**：在搜索框输入关键词，点击搜索按钮或按回车键执行搜索。
4. **分页交互**：点击分页控件切换页码，加载更多资源。

### 2.4 设计规范
- **布局规范**：采用卡片式布局，清晰展示资源信息。
- **色彩方案**：使用与文化类型相关的色彩，如非遗项目使用传统色彩，名人使用稳重的色彩。
- **字体规范**：标题使用加粗字体，正文使用清晰易读的字体。
- **视觉元素**：每个资源项包含相关的图片或图标，增强视觉效果。

### 2.5 技术实现要点
- **数据获取**：通过API调用获取文化资源数据，支持分页和筛选。
- **组件复用**：使用Vue组件复用技术，减少代码冗余。
- **状态管理**：使用Vue的响应式数据管理，实时更新页面状态。
- **路由导航**：使用Vue Router实现页面跳转和参数传递。

### 2.6 常见问题解答
- **资源加载失败**：检查网络连接，确保后端服务正常运行。
- **搜索结果不准确**：可能是关键词输入有误，或搜索算法需要优化。
- **详情页加载缓慢**：可能是资源包含大量图片或视频，建议优化媒体资源加载。

## 3. AI设计页面

### 3.1 功能概述
AI设计页面是平台的特色功能，用户可以基于江苏文化元素生成创意设计作品，支持自定义设计参数和保存管理设计作品。

### 3.2 核心组件
- **设计参数配置**：包括文化元素选择、设计风格选择、颜色方案选择等。
- **AI生成按钮**：点击触发AI设计生成。
- **设计结果展示**：展示AI生成的设计作品。
- **作品管理**：用户创建的设计作品列表，支持查看、编辑和删除。

### 3.3 交互流程
1. **参数配置**：用户选择文化元素、设计风格、颜色方案等参数。
2. **生成设计**：点击“生成设计”按钮，等待AI生成设计作品。
3. **结果查看**：查看AI生成的设计作品，可进行预览和保存。
4. **作品管理**：在作品列表中查看和管理已保存的设计作品。

### 3.4 设计规范
- **色彩方案**：使用现代、时尚的色彩，体现创意设计的特点。
- **布局规范**：采用模块化布局，清晰展示配置参数和设计结果。
- **字体规范**：使用现代无衬线字体，增强科技感。
- **视觉元素**：使用简洁、现代的图标和界面元素，符合设计工具的风格。

### 3.5 技术实现要点
- **API调用**：通过前端API调用后端AI接口，实现设计生成。
- **参数验证**：对用户输入的设计参数进行验证，确保参数有效。
- **结果处理**：处理AI返回的设计结果，确保正确展示。
- **作品管理**：通过API调用实现设计作品的保存、编辑和删除。

### 3.6 常见问题解答
- **设计生成失败**：可能是AI服务暂时不可用，或参数设置有误，建议重试或调整参数。
- **生成结果不符合预期**：可能是参数设置不够具体，建议调整设计参数，增加更多细节描述。
- **作品保存失败**：可能是网络问题或服务器错误，建议检查网络连接并重试。

## 4. 个人中心页面

### 4.1 功能概述
个人中心页面是用户管理个人信息和作品的专属空间，包括个人资料管理、作品管理、收藏管理等功能。

### 4.2 核心组件
- **个人资料**：展示和编辑用户个人信息。
- **作品管理**：展示用户创建的设计作品，支持编辑和删除。
- **收藏管理**：展示用户收藏的文化资源，支持取消收藏。
- **账户设置**：修改密码、绑定邮箱等账户相关设置。

### 4.3 交互流程
1. **资料编辑**：点击“编辑资料”按钮，修改个人信息，保存更改。
2. **作品管理**：在作品列表中查看、编辑或删除作品。
3. **收藏管理**：在收藏列表中查看或取消收藏文化资源。
4. **账户设置**：修改密码、绑定邮箱等账户设置。

### 4.4 设计规范
- **色彩方案**：使用中性、稳重的色彩，体现个人空间的私密性。
- **布局规范**：采用清晰的卡片式布局，分类展示不同功能模块。
- **字体规范**：使用清晰易读的字体，确保信息展示清晰。
- **视觉元素**：使用简洁的图标和界面元素，增强用户体验。

### 4.5 技术实现要点
- **身份验证**：通过路由守卫确保只有登录用户才能访问。
- **数据获取**：通过API调用获取用户信息、作品和收藏数据。
- **数据更新**：通过API调用更新用户信息、作品和收藏状态。
- **表单验证**：对用户输入的表单数据进行验证，确保数据有效性。

### 4.6 常见问题解答
- **无法访问个人中心**：可能是未登录或登录状态已过期，建议重新登录。
- **资料修改失败**：可能是网络问题或数据验证失败，建议检查输入数据并重试。
- **作品删除失败**：可能是网络问题或权限不足，建议检查网络连接并重试。

## 5. 登录/注册页面

### 5.1 功能概述
登录/注册页面是用户进入平台的入口，支持用户登录已有账户或注册新账户，确保用户身份的合法性。

### 5.2 核心组件
- **登录表单**：包含用户名/邮箱、密码输入框和登录按钮。
- **注册表单**：包含用户名、邮箱、密码、确认密码输入框和注册按钮。
- **密码找回**：提供密码找回功能。
- **第三方登录**：支持第三方平台登录（如微信、QQ等）。

### 5.3 交互流程
1. **登录流程**：输入用户名/邮箱和密码，点击登录按钮，验证成功后进入平台。
2. **注册流程**：输入注册信息，点击注册按钮，验证成功后自动登录并进入平台。
3. **密码找回**：点击“忘记密码”链接，按照提示找回密码。
4. **第三方登录**：点击第三方登录按钮，授权后进入平台。

### 5.4 设计规范
- **色彩方案**：使用品牌主色调，体现平台的专业性和可信度。
- **布局规范**：采用简洁的表单布局，确保用户输入体验良好。
- **字体规范**：使用清晰易读的字体，确保表单标签和提示信息清晰可见。
- **视觉元素**：使用简洁的图标和界面元素，增强用户体验。

### 5.5 技术实现要点
- **表单验证**：对用户输入的登录和注册信息进行验证，确保数据有效性。
- **API调用**：通过API调用实现登录、注册和密码找回功能。
- **JWT认证**：登录成功后生成JWT token，用于后续的身份验证。
- **路由跳转**：登录成功后跳转到首页或之前访问的页面。

### 5.6 常见问题解答
- **登录失败**：可能是用户名或密码错误，或账户被锁定，建议检查输入或联系管理员。
- **注册失败**：可能是邮箱已被注册，或密码不符合要求，建议检查输入或尝试其他邮箱。
- **密码找回失败**：可能是邮箱未注册，或验证信息有误，建议检查输入或联系管理员。

### 6.1 功能概述
非遗文化页面专门展示江苏省的非物质文化遗产项目，包括国家级、省级和市级非遗项目，为用户提供详细的非遗信息和保护状况。

- **非遗详情**：点击非遗项目查看详细信息，包括历史渊源、传承情况、保护措施等。
- **图片/视频展示**：展示非遗项目的相关图片和视频。

### 6.3 交互流程
1. **分类浏览**：点击分类导航切换不同类型的非遗项目。
2. **项目查看**：点击非遗列表项查看详细信息。
3. **媒体浏览**：查看非遗项目的图片和视频。
4. **收藏/分享**：收藏或分享感兴趣的非遗项目。

### 6.4 设计规范
- **色彩方案**：使用传统、典雅的色彩，体现非遗文化的厚重感。
- **布局规范**：采用卡片式布局，清晰展示非遗项目信息。
- **字体规范**：标题使用加粗字体，正文使用清晰易读的字体。
- **视觉元素**：使用与非遗项目相关的图片和图标，增强视觉效果。

### 6.5 技术实现要点
- **数据获取**：通过API调用获取非遗项目数据，支持分页和筛选。
- **媒体加载**：优化图片和视频的加载，确保流畅的浏览体验。
- **响应式设计**：确保在不同设备上均有良好的显示效果。
- **交互增强**：添加适当的动画和过渡效果，增强用户体验。

### 6.6 常见问题解答
- **非遗项目加载失败**：检查网络连接，确保后端服务正常运行。

- **详情页信息不全**：可能是该非遗项目的信息尚未完善，建议后续关注更新。
